# Contributing to This Portfolio

Thank you for your interest in this project! While this is a personal portfolio, contributions for bug fixes and improvements are welcome.

## 🐛 Reporting Bugs

If you find a bug:

1. Check if it's already reported in [Issues](https://github.com/mouad-dot/portfolio/issues)
2. If not, create a new issue with:
   - Clear description of the bug
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots (if applicable)
   - Environment details (OS, browser, Node version)

## 💡 Suggesting Enhancements

Enhancement suggestions are welcome! Please:

1. Check existing issues first
2. Describe the enhancement clearly
3. Explain why it would be useful
4. Provide examples if possible

## 🔧 Pull Requests

### Development Setup

```bash
# Fork and clone the repository
git clone https://github.com/YOUR-USERNAME/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Coding Standards

- **TypeScript**: Use strict mode, proper typing
- **Components**: Follow atomic design principles
- **Styling**: Use Tailwind CSS utility classes
- **Naming**: Descriptive, camelCase for variables, PascalCase for components
- **Comments**: Add JSDoc comments for complex functions

### Before Submitting

1. Run linter: `npm run lint`
2. Test in multiple browsers
3. Ensure responsive design works
4. Check accessibility (keyboard navigation, screen readers)
5. Verify performance (Lighthouse score)

### Pull Request Process

1. Create a feature branch: `git checkout -b feature/your-feature-name`
2. Make your changes
3. Commit with clear messages: `git commit -m "Add: feature description"`
4. Push to your fork: `git push origin feature/your-feature-name`
5. Open a Pull Request with:
   - Clear description of changes
   - Screenshots/GIFs of visual changes
   - Testing steps

## 📝 Commit Message Convention

```
Type: Brief description

- Detailed explanation (if needed)
- References to issues (if applicable)
```

**Types:**
- `Add`: New feature
- `Fix`: Bug fix
- `Update`: Content or dependency update
- `Refactor`: Code restructuring
- `Style`: CSS/styling changes
- `Docs`: Documentation updates
